🖼️ تعلم iframes في HTML

📌 مقدمة عن iframes

iframe = Inline Frame (إطار مضمن)

يسمح لك بتضمين صفحة ويب أخرى داخل صفحتك الحالية.

📌 ملاحظة: HTML Frames القديمة (frameset) لا تُستخدم الآن! الـ iframes هي الطريقة الحديثة والصحيحة.

1️⃣ iframe بسيط - صفحة ويب محلية

تضمين صفحة HTML أخرى:

<iframe src="about.html" width="100%" height="500"></iframe>

2️⃣ سمات iframe المهمة

السمة الوصف مثال
src مصدر الملف أو الصفحة src="page.html"
width عرض الـ iframe width="600"
height ارتفاع الـ iframe height="400"
title وصف الـ iframe (للوصولية) title="خريطة جوجل"
name اسم الـ iframe name="myframe"
allowfullscreen السماح بملء الشاشة allowfullscreen
loading تحميل كسول (lazy) loading="lazy"

3️⃣ فيديو يوتيوب

تضمين فيديو يوتيوب:

<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" allowfullscreen></iframe>

تضمين خريطة جوجل:

5️⃣ أفضل الممارسات

✅ يجب عليك:

  • استخدم title دائماً (للوصولية)
  • حدد width و height أو استخدم CSS
  • استخدم loading="lazy" لتحسين السرعة
  • أزل الحدود: style="border: none;"
  • استخدم allowfullscreen للفيديوهات

❌ تجنب:

  • عدم استخدام title (سيء للوصولية)
  • تحميل صفحات بطيئة بدون loading="lazy"
  • iframes متداخلة بكثرة (قد تبطئ الصفحة)
  • عدم اختبار الموقع على أجهزة مختلفة

6️⃣ مثال كامل - صفحة بعدة iframes

<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="UTF-8">
    <title>موقع بـ iframes</title>
</head>
<body>
    <h1>مرحباً بك</h1>

    <h2>الفيديو:</h2>
    <iframe
        width="560" height="315"
        src="https://www.youtube.com/embed/dQw4w9WgXcQ"
        allowfullscreen>
    </iframe>

    <h2>الخريطة:</h2>
    <iframe
        width="100%" height="450"
        src="https://www.google.com/maps/embed?pb=..."
        allowfullscreen=""
        loading="lazy">
    </iframe>

    <h2>صفحة أخرى:</h2>
    <iframe
        src="about.html"
        width="100%"
        height="500"
        title="صفحة معلومات">
    </iframe>
</body>
</html>

7️⃣ حالات الاستخدام الشائعة

  • 📹 فيديوهات يوتيوب - تضمين الفيديوهات
  • 🗺️ خرائط جوجل - عرض المواقع
  • 📄 مستندات جوجل - عرض الملفات
  • 📊 جداول بيانات - عرض البيانات
  • 🎵 مشغلات الموسيقى - Spotify, SoundCloud
  • 📝 صفحات ويب - تضمين صفحات محلية
  • 💬 نماذج تسجيل الدخول - من خدمات خارجية

8️⃣ أمان iframe - sandbox

استخدم sandbox لتحديد ما يمكن للـ iframe عمله:

<iframe src="untrusted.html" sandbox="allow-scripts allow-same-origin"></iframe>
الخيار الوصف
allow-same-origin السماح بالوصول للمصدر نفسه
allow-scripts السماح بتشغيل JavaScript
allow-forms السماح بإرسال النماذج
allow-popups السماح بفتح نوافذ جديدة

✅ ملخص

  • iframe تُستخدم لتضمين صفحات ويب داخل صفحة أخرى
  • استخدم src لتحديد المصدر
  • لا تنسَ title و width و height
  • استخدم loading="lazy" للأداء الأفضل
  • استخدم sandbox للأمان الأفضل
